ドライブ実況台本ジェネレーター 検証版

再生する
動画

公開動画のみ対応します（限定公開・非公開はGemini側が受け付けません）。

まずは10分程度で試すのを勧めます。長時間を一度に投げると無料枠（1日8時間）をすぐ使い切ります。

実況

景色に変化がなく、語ることがない区間で、間を持たせる独り言として使われます。
見どころが続く区間では差し込みません。頻度は区間あたり1〜2回までです。

興味・関心にnoteなどのURLを貼っておくと、その記事を読んで感想を作り、欄に書き足します。 以降はその感想が雑談の材料になります。読むのはGeminiで、1つのURLにつき1回だけです。 台本生成の前にも自動で走ります。
キャラクター設定と興味・関心はデータリポジトリの character/ に置けます（設定のステップ4）。 置いておくと claude.ai/code でリポジトリを開いて書き換えられ、作られた感想もそこへ残ります。

実況＝目の前のもの・標識・場所についての発話。雑談＝独り言や連想など、映っているものに依らない発話。
上限であり目安でもあります。上げると細かい対象（歩行者・看板の文字・空の色・音）まで拾い、下げると大きな変化だけに絞ります。
見どころが続く区間では雑談が減り、何もない区間では実況が減って雑談が埋めます。
信号での停止・発進は、その操作自体を実況しません。ただし信号待ちは雑談に向くので、独り言は入りえます。

コメント欄（任意）

YouTube用のAPIキーが必要です（設定のステップ3）。日本語コメントのみ抽出します。
視聴者同士のやり取りは、上限まで読み上げてからスレッド全体に1回だけ反応します。超えた分は省略されます。

セットアップ

キーはこの端末のブラウザ内（localStorage）にのみ保存されます。送信先はGoogleのAPIだけです。

1Gemini APIキー（必須）

  1. Google AI Studio のAPIキー画面を開く
    https://aistudio.google.com/apikey
  2. 「APIキーを作成」を押す
  3. プロジェクトを選ぶ画面が出たら 新しいプロジェクトで作成 を選ぶ
    既に使っているCloudプロジェクトがあればそれでも構いません。迷ったら新規で。
  4. 表示された AIza… をコピーして下に貼る

無料枠あり・カード登録不要。ただし動画の解析は1日8時間までです。
キーは後からでも同じ画面で再表示できるので、控えを取り損ねても大丈夫です。

新規と既存、どちらを選ぶべきか

新規を勧めます。無料枠はプロジェクト単位なので、専用にしておけば他の用途と枠を食い合いません。 不要になったらプロジェクトごと消せますし、有効化するAPIもこのアプリの分だけで済みます。

新規で作ると gen-lang-client-0123456789 のような自動生成の名前が付きます。 ステップ3でこの名前を選ぶ必要があるので、控えておいてください。

2モデルを選ぶ

既定のまま試して動けばそれでOKです。
モデル名は頻繁に入れ替わります。エラーが出たら「一覧を取得」で、あなたのキーで今使えるものを確認できます（キーの疎通確認も兼ねます）。

どれを選べばいいか

Flash系を勧めます。ドライブ動画は尺が長く、映像は1秒あたり数百トークンを消費するため、 Pro系だと解析コストが跳ね上がります。台本の面白さは主にキャラクター設定で決まるので、 まずFlashで試して、物足りなければ上位を試す順番が無駄がありません。

一覧には動画を扱えないモデルも混ざります（埋め込み・画像生成・音声など）。 gemini-…-flash か gemini-…-pro の名前のものを選んでください。

3YouTubeのコメント取得（使うときだけ）

YouTube専用のAPIキーを作ってください。 AI Studioで作ったキーは Generative Language API 専用に発行されることが多く、 YouTube Data API を有効化しても、キーの「APIの制限」に追加できないため兼用できません。

  1. プロジェクトを作成する（名前は何でもよい。既存のものでも可）
  2. YouTube Data API v3 を有効にする
    ※画面上部のプロジェクト選択が1のものになっているか確認
  3. 認証情報で「認証情報を作成」→「APIキー」
    ※「サービスアカウントを介してAPI呼び出しを認証する」はチェックしない（チェックすると使えなくなります）
  4. できた AIza… を下に貼って「接続テスト」

Geminiのキーを兼用したい場合

多くの場合できません。AI Studioのキーは Cloud Console の認証情報一覧に現れないか、 現れても「APIの制限」に YouTube Data API v3 を追加できません。試すなら、 キーのプロジェクトで YouTube Data API v3 を有効化したうえで、 認証情報からそのキーの制限に追加できるか確認してください。追加できなければ諦めて上の手順で作ってください。

Cloud Console にプロジェクトが出てこないときは、ログイン中のGoogleアカウントが違うか、 プロジェクト選択ダイアログで「すべて」タブを見ていないのが原因のことが多いです。

無料枠は1日10,000ユニット。コメント取得は1回1ユニットなので、通常は使い切りません。

4データリポジトリ（任意）

キャラクター設定と興味・関心を、自分のプライベートリポジトリに置いて使うための設定です。 claude.ai/code でそのリポジトリを開けば、内容の書き換えをAIに頼めます。 実況プレイヤー側で設定済みなら、ここは空欄のままで構いません（同じ設定を共有します）。

  1. このリンクからプライベートリポジトリを作る（名前と非公開が入力済み）。既存のものを使うなら飛ばせます
  2. このリンクから Fine-grained トークンを発行する。Token name の例は drive-wipe です
    • Expiration：90 days か Custom→1年後
    • Repository access：Only select repositories → 1で作ったリポジトリ
    • Repository permissions：Contents: Read and write だけ
  3. 表示された github_pat_… を上に貼って「保存」
    この画面を閉じるとトークンは二度と表示されません。

設定すると、次回このページを開いたときに character/ の内容を自動で読み込みます。 読み込めなかった場合は、この端末に保存されている内容をそのまま使います。
