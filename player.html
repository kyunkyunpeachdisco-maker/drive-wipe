データリポジトリ（端末間の受け渡し）

PCで作った音声をスマホで鳴らすための置き場です。台本と音声をあなたのプライベートリポジトリに保存し、別の端末で取り込みます。 取り込んだ音声はエンジンの設定に関係なく再生されるので、スマホに内蔵音声しかなくてもPCで作った声で鳴ります。

初回の準備（3ステップ）

ステップ1：プライベートリポジトリを作る
このリンクから作成（名前と非公開が入力済み）
「Create repository」を押すだけです。すでに使いたいリポジトリがあれば、この手順は飛ばせます。

ステップ2：Fine-grained トークンを発行する
このリンクから発行（Token nameが入力済み）
Token name の例は drive-wipe です。次の3つを設定してください。

  1. Expiration：90 days か Custom→1年後（切れたら再発行して貼り直すだけです）
  2. Repository access：Only select repositories → ステップ1のリポジトリを選ぶ
  3. Repository permissions：Contents: Read and write だけ

「Generate token」を押し、表示された github_pat_… をコピーします。 この画面を閉じるとトークンは二度と表示されません。

ステップ3：上の2つの欄に入れて「保存」
複数の端末で使う場合は、同じ2つを各端末で入力してください。
初回の保存時に、リポジトリへ案内ファイル（CLAUDE.md）を自動で作成します。これがあると、 claude.ai/code でこのリポジトリを開いたときにデータの場所と構造が伝わり、台本の書き換えを頼めます。 すでにCLAUDE.mdがある場合は何もしません。

音声

Gemini音声とは別のサービスです（Cloud Text-to-Speech）。無料枠は WaveNet・Standardが月400万文字、Neural2・Chirp3が月100万文字で、 ドライブ動画1時間ぶんの台本でも2万文字程度なので、実質使い切れません。
手順：① Cloud Text-to-Speech API を有効化 → ② APIキーを発行 → ここに貼る。
YouTubeのキーと同じプロジェクト・同じキーが使えます（キーに「APIの制限」を掛けている場合は、そこにCloud Text-to-Speech APIを追加してください）。 プロジェクトに請求先アカウントの紐付けを求められることがありますが、無料枠の内側なら請求は発生しません。

Gemini音声は上から穏やか → 明るい → 力強い → 説明向きの順に並べてあります。 括弧内は公表されている声の特徴です。「声を確認」で聴き比べてください。
落ち着いた独り言なら Achernar Vindemiatrix Callirrhoe あたりが合います。

Gemini音声の無料枠は1日あたりの生成回数がかなり少なく、台本1本ぶんを賄えないことがあります。 上限に当たった場合は待っても同じ日のうちは空かないので、「Google Cloud音声」に切り替えてください（同じくらい自然で、無料枠は桁違いに大きく、スマホからも作れます）。 生成した音声は端末に保存されるため、同じセリフを作り直して枠を減らすことはありません。

アバターの調整

上が実際のワイプです。下の設定を変えると、ここにそのまま反映されます。
VRMを選んだ時点で、体格に合わせて自動で画角を決めます。 ワイプの形や横からの角度を変えた後は「自動で合わせる」でやり直せます（手で変えた値は初期値に戻ります）。

ハンドルの入れ具合は、体とハンドルのどちらを画面の中心に置くかです（0で体、1でハンドル）。 画角は「頭＋肩」「ハンドルまで」が入る距離を自動で計算します。寄りは倍率（小さいほど寄る）、 上下位置は人物を画面のどこに置くかです。設定は保存されます。
「ハンドルまで映す」を選ぶと腕とハンドルが出ます。ハンドルの位置を先に決め、手はその縁を掴みにいきますので、 まず大きさ・傾き・高さ・前後でハンドルを置いてください。腕は自動で追従します。 手を握る位置は左が9時15分・中央が10時10分・右が11時5分、肘の張り出しは肘を外に開く量です。
VRMを選ばない間は、動作確認用の簡易アバターが表示されます。

VRMファイルはどこで手に入れる？

まずは配布モデルを1つ落として試すのを勧めます。自作は時間がかかるので、 画角や動きが好みに合うか確かめてからで十分です。

選ぶときの目安

  1. 軽いモデルを選ぶ。ワイプは小さいので高精細は不要で、重いとiPhoneが発熱します
  2. 胸から上が作り込まれているもの。この画角では顔と上半身しか映りません
  3. VRM 0.x でも 1.0 でも読めます。背中を向いたら「向きを反転」で直ります

ライセンスの見方

  1. 配布ページの利用条件が「設定されていません」の場合、それは許可ではなく未設定です。 商用利用・改変・再配布は許可されていないものとして扱ってください
  2. 自宅で個人的に見るだけなら、通常はダウンロード時に同意する利用規約の範囲です
  3. VRMファイルをこのリポジトリに入れないこと。公開されるため再配布にあたります。 このアプリは端末内（IndexedDB）に保存するだけなので、そのまま使えば問題ありません
  4. 「親作品」がある二次利用モデルは、元の作者やキャラクターの権利も重なります。 公開する予定があるなら、条件が明記されたモデルを選ぶほうが安全です

実写にしたい場合：VRMは基本的にアニメ調です。実写寄りにするなら、 写真と音声から動画を作って読み込む方式が必要になります（未実装）。

再生

「音声をまとめて用意」を先に実行すると、再生中に音声を作らないため利用上限に当たりません。 作った音声は端末に保存され、同じ台本の2回目以降は生成なしで再生できます。
iPhoneでは最初の再生に画面のタップが必要です。この「再生を開始」がその操作を兼ねています。
